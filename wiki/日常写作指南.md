# 日常写作指南

## 文章文件命名

在 `_posts/` 下新建文件，命名必须为：

```text
年-月-日-英文短名.md
```

命名或日期格式不正确会导致文章不显示。

## Front Matter 模板

```markdown
---
title: "中文标题"
title_en: "English Title"
summary: "首页列表里显示的一两句话。可以不写。"
date: 2026-09-15
lang: zh
---

正文从这里开始。
```

`lang` 可填 `zh` 或 `en`，`zh` 会自动两端对齐。

## 常用写作元素

- 脚注：正文 `[^标签]`，文末 `[^标签]: 内容`
- 引用：行首 `>`
- 图片：压缩为 WebP 放入 `assets/img/`，建议全宽图控制在 100KB 内
  - 推荐工具：[Squoosh](https://squoosh.app)
  - 引用方式：`![说明](/assets/img/文件名.webp)`
- 视频：不要上传视频文件到仓库，使用嵌入播放器

```html
<div class="embed">
<iframe src="https://www.youtube-nocookie.com/embed/视频ID" title="标题" loading="lazy" allowfullscreen></iframe>
</div>
```

`.embed` 会保持 16:9 比例，`loading="lazy"` 可减少首屏压力。

## 大文件建议

讲稿 PDF、数据集等大文件建议放在 GitHub Releases 或 Zenodo，再在文章中外链引用。
