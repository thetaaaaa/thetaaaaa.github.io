# 字体与本地预览

## 字体策略

- 西文正文：Source Serif 4
- 中文正文：系统宋体（Mac 上通常为 Songti SC）

如果 Windows 下宋体显示偏细，可将 `_config.yml` 中：

```yaml
typeface: serif
```

改为 `sans`，中文将切换到黑体（苹方 / 思源黑体 / 微软雅黑）。

## 本地预览（可选）

不进行本地预览也可直接推送到 GitHub 查看效果。

如需本地运行：

```bash
gem install bundler
bundle install
bundle exec jekyll serve
```

访问：`http://localhost:4000`
