# 快速上线

## 1. 建仓库

登录 GitHub，新建一个**公开**仓库，名字必须严格是：

```text
你的用户名.github.io
```

例如用户名是 `litao`，仓库名就是 `litao.github.io`。
这是 GitHub 识别「个人主站」的唯一命名方式。

## 2. 上传文件

将本项目全部文件放入仓库根目录，可任选一种方式：

- 网页上传：仓库页面 → Add file → Upload files。
- 命令行：

```bash
git init
git add .
git commit -m "初始站点"
git branch -M main
git remote add origin https://github.com/你的用户名/你的用户名.github.io.git
git push -u origin main
```

## 3. 打开 Pages

仓库 → Settings → Pages：

- Source：**Deploy from a branch**
- Branch：`main`
- Folder：`/ (root)`

保存后等待 1~2 分钟，站点即可访问：

```text
https://你的用户名.github.io
```
